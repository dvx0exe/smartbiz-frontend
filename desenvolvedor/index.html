SmartBiz

Gestão com IA para microempreendedores: PDV, estoque, clientes, fluxo de caixa e notas fiscais.

  • API em Java 17 e Spring Boot com MongoDB; frontend estático no GitHub Pages.

  • Notas fiscais em modo simulado, sem transmissão à SEFAZ.

Secret Friend API

Amigo secreto com sorteio, sugestões de presente por IA e resultado por e-mail.

  • API REST com PostgreSQL e Spring Data JPA; convites por UUID.
  • Login Google (OAuth2) para organizadores; participantes entram por código.
  • Se a IA falha, o sorteio continua; e-mail e IA rodam em threads assíncronas.
  • Testes com JUnit 5 e Mockito nas regras do sorteio. CI no GitHub Actions e deploy no Render.

Mini Plotter CNC 2D

Máquina de desenho feita com peças de duas impressoras HP descartadas e controlada por Arduino Uno. Trabalho em trio na Uniube.

  • Firmware em C++ que desenha formas geométricas, com aceleração via AccelStepper e caneta levantada por servo.
  • Modo de diagnóstico com cronômetro expôs a perda de passos dos motores 28BYJ-48, que operam sem feedback de posição.
  • Pendente: a aplicação em C# que enviaria os comandos por Serial ainda não está integrada.
